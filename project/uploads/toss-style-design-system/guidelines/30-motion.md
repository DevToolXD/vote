# 모션

TDS의 모션은 스프링 기반이에요. 누르는 순간 반응하고, 빠르게 시작해 부드럽게 멈춰요. `prefers-reduced-motion`이면 이동과 크기 변화를 빼고 투명도만 바꾸세요.

## 스프링 토큰

모두 mass 1이에요.

| 이름 | stiffness | damping | 쓰는 곳 |
| --- | --- | --- | --- |
| rapid | 1000 | 55 | 버튼 누름, 오버레이 닫힘 |
| quick | 800 | 55 | 상태 전환, 누름에서 복귀, 오버레이 열림 |
| small | 480 | 50 | 토스트 등장·퇴장 |
| bounce | 300 | 15 | 통통 튀는 강조 |
| medium | 270 | 25 | 일반 전환 |
| basic | 200 | 30 | 나타나기 |
| large | 100 | 15 | 큰 요소 이동 |
| slow | 70 | 20 | 느린 연출 |

## 베지어 이징

| 이름 | cubic-bezier | 비고 |
| --- | --- | --- |
| out | 0.25, 0.1, 0.25, 1 | 기본값, 0.5초 |
| ease | 0.6, 0, 0, 0.6 | 딤·그라디언트 페이드 0.4초 |
| expo | 0.16, 1, 0.3, 1 | 빠르게 시작해 길게 감속 |
| back | 0.34, 1.56, 0.64, 1 | 살짝 넘쳤다 돌아옴 |
| linear | 0, 0, 1, 1 | |

CSS에서 스프링을 흉내 낼 때는 `rapid`/`quick`을 0.15~0.2초 `cubic-bezier(0.16, 1, 0.3, 1)`로, `small`을 0.3초 같은 곡선으로 근사하세요.

## 자주 쓰는 수치

| 상황 | 값 |
| --- | --- |
| 버튼 누름 | `scale(0.96)`, rapid. 전체 너비로 붙은 버튼은 축소 없음 |
| 버튼 색 전환 | 0.1초 ease-in-out |
| 버튼 로딩 | 배경이 0.6초 간격으로 왕복 깜빡임, out |
| 스위치 | 손잡이 16px → 24px로 커지며 16px 이동, 트랙 grey200 → blue500 |
| 토스트 | 위에서 46px 지점까지 내려옴, small. 3초 뒤 사라짐 |
| 다이얼로그 | 딤과 본문 투명도 quick로 열림, rapid로 닫힘 |
| 바텀시트 | 아래에서 올라옴. 닫기 금지일 때 딤을 누르면 좌우로 2 → −2 → 1 → −1 → 0px 흔들림 |
| 숫자 변화 | 자릿수가 굴러가듯 바뀌는 롤링 |
| 완료 | 원 → 체크 순서로 그려지는 체크 애니메이션 |
