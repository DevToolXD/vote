# 화면 패턴

## 한 화면에 한 질문

긴 폼 하나 대신 짧은 질문 여러 화면으로 나눠요. 송금이라면:

| 단계 | 제목 | 화면 구성 |
| --- | --- | --- |
| 1 | 누구에게 보낼까요? | 최근 보낸 사람 목록(`ListRow`), 검색 |
| 2 | 얼마를 보낼까요? | `TextField` hero형 금액 + 숫자 키패드 + 빠른 금액 칩(+1만, +5만, +10만, 전액) |
| 3 | 김하늘님에게 50,000원을 보낼까요? | 받는 사람·금액·출금 계좌 요약(`ListRow`), `BottomCTA` "보내기" |
| 4 | 50,000원을 보냈어요 | 가운데 체크 애니메이션, 요약, `BottomCTA` "확인" |

- 화면에 들어오면 입력 칸에 바로 포커스하고 키보드를 띄워요.
- 값이 유효해지면 하단 버튼이 활성화돼요. 한 칸짜리 입력은 다 채우면 다음 단계로 바로 넘어가도 돼요.
- 앞 단계에서 받은 값을 다음 제목에 다시 넣어 맥락을 이어가요.

## 화면 골격

1. 상단 바: 뒤로 가기 버튼만 두고, 가운데 제목은 비워 둬요.
2. `Top`: 본문 첫머리에 큰 제목(`page-title`)과 부제(`description`, `grey600`).
3. 콘텐츠: 목록, 입력, 금액.
4. `BottomCTA`: 화면 아래 고정, 좌우·아래 20px, 위로 36px 그라디언트. 키보드가 올라오면 키보드 바로 위로 따라가요.

## 선택은 바텀시트로

짧은 선택(은행 고르기, 기간 고르기, 정렬)은 새 화면 대신 `BottomSheet`로 처리해요. 제목은 질문형, 내용은 `ListRow` 목록이에요.

## 확인과 되돌리기

- 되돌릴 수 있는 행동은 바로 실행하고 `Toast`로 알려요.
- 되돌릴 수 없는 행동(송금, 해지, 삭제)만 확인 화면이나 `ConfirmDialog`로 한 번 더 물어요. 위험한 행동의 확인 버튼은 `color="danger"`.
- 송금 확인에서는 받는 사람 이름과 금액을 가장 크게 보여줘요.

## 오류

- 입력 오류는 입력 칸 바로 아래 도움말 자리에 `red600`으로 써요.
- 시스템 오류는 가운데 정렬된 결과 화면: 그림 하나, 제목("잠시 문제가 생겼어요"), 설명 한 줄, "다시 시도하기" 버튼.

## 완료 화면

가운데 큰 체크(원이 그려진 뒤 체크가 그려지는 애니메이션), 과거형 제목("신청했어요"), 핵심 요약, "확인" 버튼 하나. 가운데 정렬은 이 화면과 빈 상태에서만 써요.

## 금융 화면

- 잔액·자산·결제 금액이 주인공이에요. `amount-hero`, `grey900`.
- 증감은 부호와 색을 함께: `+12,300원 (+2.4%)` `red500`, `−5,000원 (−1.1%)` `blue500`.
- 큰 금액은 한글 단위로 줄여 읽기 쉽게: `1억 2,500만원`.
- 홈은 계좌·카드·대출·투자를 `ListRow` 목록으로 모으고, 섹션은 16px `greyBackground` 띠로 나눠요.
- 비밀번호는 전용 보안 키패드로 받아요.
