# 보이스와 톤

목소리는 **친절하고 믿을 수 있는 친구**예요. 은행원처럼 딱딱하지도, 광고처럼 들뜨지도 않아요.

## 다섯 가지 가치

- **Clear**: 누가 읽어도 한 번에 이해돼요.
- **Concise**: 필요한 말만 해요.
- **Casual**: 금융·IT 용어 대신 일상 언어를 써요.
- **Respect**: 가르치거나 몰아붙이지 않아요.
- **Emotional**: 정보 너머 사용자의 감정을 헤아려요.

## 쓰고 나서 점검하는 여덟 가지

1. **Predictable hint**: 버튼과 제목만 보고 다음 화면을 예상할 수 있나요?
2. **Weed cutting**: 뜻에 영향이 없는 단어를 모두 뺐나요?
3. **Remove empty sentences**: 뜻 없는 문장을 모두 뺐나요?
4. **Focus on key message**: 정말 중요한 메시지 하나만 남았나요?
5. **Easy to speak**: 소리 내어 읽었을 때 어려운 말이 없나요?
6. **Suggest than force**: 행동을 강요하거나 겁주지 않나요?
7. **Universal words**: 누구나 이해하고, 누구에게도 해가 되지 않나요?
8. **Find hidden emotion**: 사용자의 감정에 공감했나요?

## 문장 규칙

- 모든 문구는 **해요체**예요. 상황을 가리지 않고 통일해요.
- 과한 경어를 빼세요: "입력하여 주시기 바랍니다" → "입력해주세요".
- **능동형**: "신청이 접수되었습니다" → "신청을 받았어요".
- **긍정형**: "영업일이 아니면 이체할 수 없습니다" → "영업일에 다시 이체할 수 있어요".
- 사용자를 탓하지 마세요: "잘못된 계좌번호입니다" → "계좌번호를 다시 확인해주세요".
- 시스템 오류는 담담하게: "오류가 발생하였습니다" → "잠시 문제가 생겼어요".

## 요소별 쓰는 법

| 요소 | 규칙 | 예 |
| --- | --- | --- |
| 화면 제목 | 질문형 또는 결과형, 두 줄 이내 | 누구에게 보낼까요? / 대출 한도를 확인했어요 |
| 부제 | 제목을 보충하는 한 문장 | 언제든 바꿀 수 있어요 |
| 주요 버튼 | 짧은 동사, 2~6글자 | 다음 · 확인 · 보내기 · 시작하기 |
| 결과가 큰 버튼 | 무엇을 하는지 구체적으로 | 50,000원 보내기 · 해지하기 |
| 다이얼로그 | 제목은 질문, 버튼은 "닫기" + 구체적 행동 | 카드를 해지할까요? → [닫기] [해지하기] |
| 토스트 | 결과를 짧게, 과거형 | 계좌번호를 복사했어요 |
| 빈 상태 | 상황 + 다음 행동 | 아직 거래 내역이 없어요 |
| 입력 오류 | 해결 방법 | 숫자만 입력해주세요 |
| 금액 | 쉼표, 단위 붙여 쓰기 | 1,250,000원 · 연 3.5% · +12,300원(+2.4%) |
