# Top

화면 제목을 내비게이션 바가 아니라 본문 첫머리에 크게 쓰는 블록이에요.

## 넘겨주는 것

- `title`: 질문형("누구에게 보낼까요?") 또는 결과형("50,000원을 보냈어요"). 두 줄 이내.
- `subtitle`: 제목 아래 한 문장(`grey600`, 15px, 제목과 4px 간격).
- `subtitleTop`: 제목 위 작은 문장(선택).
- `upper` / `lower`: 제목 위·아래에 붙는 요소(각각 16px 간격). 예: 아이콘, 금액, 칩.
- `right`: 제목 오른쪽 요소(예: medium 버튼).
- `size`: `medium`(기본, 22px) · `large`(26px).
- `as`: 제목 태그(기본 `h1`).

## 쓰는 법

- 위아래 여백 24px, 왼쪽 24px(`gutter`)이에요(TDS Top 기본값).
- 제목은 왼쪽 정렬, `grey900`, 굵기 700이에요. 크기는 TDS 기본값이 공개되지 않아 토스 앱에서 관찰한 22~26px로 두었어요.
