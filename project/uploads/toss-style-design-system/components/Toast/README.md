# Toast

행동의 결과를 짧게 알리는 흰색 알약이에요. 화면 위에서 내려와 3초 뒤 사라져요.

## 넘겨주는 것

- `open`, `text`, `onClose`(시간이 지나면 불려요), `duration`(ms, 기본 3000, `Infinity`면 유지)
- `icon`: 왼쪽 24px 아이콘이나 이모지(오른쪽으로 8px)
- `multiline`: 여러 줄이면 모서리를 20px로
- `inline`: 고정 위치 대신 흐름 안에 그려요(미리보기, 문서용)

## 쓰는 법

- 배경 `toastBackground`(라이트 흰색, 다크 `#3c3c47`), 글자 `toastText` 15px 600, 그림자 `shadow-float`.
- 안쪽 12px 16px(아이콘이 있으면 왼쪽 12px), 너비는 내용만큼, 최대 `min(375px, 화면 - 36px)`.
- 화면 위에서 46px 지점까지 스프링(`small`)으로 내려와요.
- 문구는 과거형 한 문장: "계좌번호를 복사했어요".
