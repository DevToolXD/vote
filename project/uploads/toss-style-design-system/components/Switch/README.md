# Switch

켜고 끄는 설정이에요. 목록 행 오른쪽에 둬요.

## 넘겨주는 것

- `checked`(제어) 또는 `defaultChecked`, `onChange(next)`, `disabled`, `aria-label`(필수: 무엇을 켜는지)

## 쓰는 법

- 트랙 50×30px, 모서리 15px. 꺼지면 `grey200` 트랙에 16px 흰 동그라미, 켜지면 `blue500` 트랙에 24px로 커진 동그라미가 16px 오른쪽으로 가요.
- 누르면 0.96배로 줄고 트랙이 한 단계 진해져요(`grey400` / `blue700`).
- 비활성은 불투명도 0.3이에요.
