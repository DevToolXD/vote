# BottomCTA

화면의 다음 행동을 엄지가 닿는 화면 아래에 고정해요. 토스 화면에서 가장 상징적인 요소예요.

## 넘겨주는 것

- `children`: `Button` 하나(`display="block"`) 또는 두 개. 두 개면 왼쪽이 보조(`variant="weak" color="dark"`), 오른쪽이 주요(fill)예요. 간격은 8px이에요.
- `fixed`: 기본 `true`(화면 아래 고정, `z-bottom-cta` 50). `false`면 흐름 안에 둬요.

## 쓰는 법

- 좌우·아래 여백은 `gutter-cta`(20px), 기기 안전 영역이 더 크면 그 값을 써요.
- 버튼 위 36px(`cta-fade`)에 배경색 → 투명 그라디언트가 있어서 스크롤되는 내용이 버튼 밑으로 자연스럽게 사라져요.
- 본문 맨 아래에 이 영역 높이만큼 빈 공간을 둬서 마지막 내용이 가려지지 않게 하세요.
- 키보드가 올라오면 키보드 바로 위로 따라 올라가게 만드세요.
