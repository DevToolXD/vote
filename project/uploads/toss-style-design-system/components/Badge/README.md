# Badge

"NEW", "혜택", "D-3"처럼 한두 단어짜리 상태 라벨이에요.

## 넘겨주는 것

- `color`: `blue`(기본) · `teal` · `green` · `red` · `yellow` · `elephant`(회색)
- `variant`: `weak`(기본, 16% 옅은 배경 + 진한 글자) · `fill`(채운 배경 + 흰 글자, yellow만 `grey800` 글자)
- `size`: 옆 글자 크기에 맞춰요. `xsmall`(9px, 11~13px 글자 옆) · `small`(10px, 14~17px 옆, 기본) · `medium`(11px, 18~21px 옆) · `large`(12px, 22~25px 옆)

## 쓰는 법

- 글자는 bold예요. weak를 기본으로 쓰고, 정말 강조할 때만 fill을 써요.
- 문장이나 설명을 넣지 마세요. 한두 단어만.
