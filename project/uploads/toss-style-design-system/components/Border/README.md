# Border

구분선이에요. 테두리 상자 대신 이것으로 영역을 나눠요.

## 넘겨주는 것

- `variant`: `full`(기본, 전체 너비 0.5px 선) · `padding24`(왼쪽 24px 들여쓴 0.5px 선, 목록 항목 사이) · `height16`(16px `greyBackground` 띠, 섹션 사이)

## 쓰는 법

- 선 색은 `hairline`이에요. 라이트 `rgba(0,0,33,0.07)`으로 `hairlineBorder`보다 훨씬 옅어요.
- 같은 섹션 안은 선이나 여백으로, 다른 섹션 사이는 16px 띠로 나눠요.
