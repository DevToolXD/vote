# ListRow

토스 화면의 대부분을 차지하는 목록 행이에요. 계좌, 사람, 설정, 거래 내역을 모두 이걸로 보여줘요.

## 넘겨주는 것

- `left`: 아이콘, 로고, 아바타(`TossStyle.Avatar`로 이니셜 원), 이모지. 오른쪽으로 16px 띄워요.
- `title`: 17px, 500, `grey800`.
- `description`: 15px, `grey600`.
- `right`: 값(금액은 600, `grey900`), `Badge`, `Switch`.
- `arrow`: 오른쪽 꺾쇠(`grey400`). 누르면 다른 화면으로 가는 행에만.
- `divider`: 행 아래에 왼쪽 24px 들여쓴 0.5px `hairline` 선.
- `onClick`: 있으면 버튼이 되고 눌림 하이라이트가 생겨요.

## 쓰는 법

- 여백은 왼쪽 24px, 오른쪽·위아래 16px, 텍스트 줄 높이 1.35예요.
- 눌림은 행 전체 색이 바뀌는 게 아니라, 행 안쪽 위아래 4px·좌우 6px 떨어진 12px 둥근 사각형이 `greyOpacity100`으로 나타나요.
- 목록은 `ul.ts-list` 같은 흰 배경 위에 쌓고, 성격이 다른 목록 사이는 `Border variant="height16"`으로 나누세요.
- 아이콘 파일은 포함되어 있지 않아요. 꺾쇠는 단순한 대체 도형이에요.
